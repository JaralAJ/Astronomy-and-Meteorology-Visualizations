# Astronomy-and-Meteorology-Visualizations
This project used astronomy datasets to build informative visualizations that make complex space data easier to explore and understand.

Credits: This Python tutorial was originally developed by Dr. Raja GuhaThakurta and his astronomy graduate students as part of the Science Internship Program (SIP) for Bay Area high school students at the University of California Santa Cruz (UCSC). Dr. GuhaThakurta's tutorial is called Python and Research (PyaR).
